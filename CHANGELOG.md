# Change Log

All notable changes to the "InspireDev" extension will be documented in this file.

This project adheres to [Keep a Changelog](http://keepachangelog.com/).  

## [1.8.0] - 2025-01-27
### Added
- **New Quotes**: Added a collection of new motivational and humorous quotes in English, French, and Spanish.

### Updated
- **Documentation**: Updated the README file with new screenshots showcasing the extension's features and improved settings descriptions.

## [1.7.0] - 2024-08-30
### Added
- **Random Sound Feature**: Introduced a random sound notification feature (`inspiredev.soundName`).
  
### Changed
- **Command Update**: Renamed the "Shuffle Quote" command to "InspireDev: Random Quote" in Visual Studio Code.
- **Default Setting**: Updated the default value for the `inspiredev.quoteFormat` setting.

## [1.6.0] - 2024-08-29
### Added
- A new logo for the extension.

## [1.5.0] - 2024-08-29
### Changed
- Renamed the extension to **InspireDev** to better reflect its purpose.

## [1.4.0] - 2024-08-29
### Added
- New language options and additional audio files.

### Fixed
- Resolved issues with `package.json`.

## [1.3.0] - 2024-08-29
### Added
- A variety of new audio tracks.
- Implemented a language selection system.

### Fixed
- Versioning error.

## [1.0.0] - 2024-08-29
### Added
- Core features including daily motivational quotes and status bar integration.
